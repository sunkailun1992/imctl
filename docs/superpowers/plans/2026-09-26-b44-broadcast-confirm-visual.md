# B44 实施计划

1. `BroadcastConfirm.swift` 将跨窗枚举改为失败关闭，并在唯一任务证明后给出只读观察与 checkpoint 后即时复核挂钩；原 `AXPress` 和 AX 后验不动。
2. 在命令处理器为显式 `broadcast.confirm` 安装限域视觉状态：冻结主窗、任务窗、PID、面板、按钮、`msgid` 和视觉设置；逐轮重验暂停、策略、授权及 AX 全局唯一性。
3. 视觉运行器只允许 `verify/reobserve/stop`，候选限 AX 已证明的唯一按钮，绝不执行模型提议的按键。按钮消失或禁用时直接沿 AX 后验；未消失且仍是同一面板才可二次观察。
4. 用合成窗口、截图与模型测试唯一成功、重观察、模型拒绝、漂移、跨窗枚举错误、AX-only 和按后未消失；协议与门报告明确真实群发未验收。
