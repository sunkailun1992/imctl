# B37：群名编辑视觉观察实施计划

1. 复用 B36 的被动观察器，新增仅接受 `.groupRename`、`.groupNameField`、唯一 `AXTextField` 的窄入口。模型允许步骤固定为 `verify/reobserve/stop`；观察器只返回模型否决或复核请求，不能写群名或执行 `AXConfirm`。
2. 在 `WeComCommandHandler.groupRename` 已通过策略、身份与目标会话选择之后安装方法专属闭包。冻结窗口 / PID / 字段 / 选中旧群行与策略，按现有命令 6 轮、40 秒预算重核录屏和视觉设置。仅遍历右标题带的少量 AX 节点，超过上限或出现多个编辑框直接停止，不扫描完整聊天表。
3. 原 `applyGroupName` 在聚焦并重核旧值之后调用第一轮；写值及最多一次同字段重写仍由动作层执行；最终精确读回后调用第二轮；两次通过后才运行原 checkpoint、单次确认及选中行后验。视觉失败不自动重试确认，也不清除可能被人工修改的编辑草稿。
4. Fake AX 覆盖两轮成功、前后停止、非法模型动作、权限关闭、双编辑框、策略 / 选中行 / 字段漂移与视觉关闭的零请求路径。主执行者再做全量回归、安装版读写活体验收和门报告分层记录；没有真实千问计数与列表行后验时保留“待活体”。
