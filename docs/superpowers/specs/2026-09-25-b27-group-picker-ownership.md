# B27：选人面板归属与联系人滚动安全边界

## 范围

显式 `contact.list` 与 `group.create` 共用 `openGroupPicker`。命令发出 ⌘N 前，主窗口不得已有任何 `AXSheet`；动作后只接受同一 PID、窗口句柄和 frame 中唯一新出现、标题精确为“发起群聊”的面板，且搜索框、空已选表、“完成”和“取消”可读。已有的“添加群成员”、发起群聊或其它面板属于用户当前状态，不复用、不取消，也不发送快捷键。

`contact.list` 读取选人列表时，只在大纲的直接父区有唯一可写 `AXScrollBar` 时逐位置滚动并读回值；多个可写轨道暂时明确失败，不选第一条，不返回可能漏项的列表。普通唯一 AX 路径不截图。当前选人面板没有足够的 AX 证据证明歧义轨道对应同一联系人列表及全部结果，因此本批不向视觉 runner 授权写滚动条；等有脱敏 AX 样本和完整性后验再单独扩展。

## 安全与验收

取消前重定位本命令打开的唯一“发起群聊”面板，确认句柄与标题；取消后读回无 `AXSheet`。弹窗变更或无法读回关闭，命令失败。`group.create` 的成员搜索、完成按钮、checkpoint 和不可逆后验保持原路径。协议、策略、MQTT 结果与按键清单不变。

Fake AX 覆盖已有添加成员面板、错误 / 多面板、正常打开并取消，以及多个滚动条时零滚动写与安全取消。本批不操作真实企微、不创建群、不发送。
