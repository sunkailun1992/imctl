# B42：添加客户搜索与邀请前的有界视觉观察

## 口径

- 只对显式 `contact.add` 生效。当前命令先证明企微仅有主窗，再由自身点击「新的客户」标题栏的「添加」，并读到新出现的唯一空白「添加客户」窗口。已有搜索窗或其它第二窗一律拒绝，不接管。
- 电话、来源、问候语、搜索回车、匹配按钮和邀请确认均由固定命令决定。模型只能对唯一 AX 搜索框、唯一来源匹配按钮和唯一邀请按钮返回 `verify`、`reobserve` 或 `stop`；不能提供文本、坐标或按压。
- 每轮和每次 AX 写前重查显式命令、暂停、实时策略、号码许可、屏幕录制 / 整窗授权、PID、主窗与搜索窗身份。模型与授权变化即停；视觉结果不代替 checkpoint 或客户端后验。
- `dryRun` 仅搜索并列出匹配，绝不按来源匹配或邀请确认。截图及模型原文只在内存中处理，不进结果、事件与日志。

## 验收界限

合成窗口与假传输覆盖成功和失败关闭。真实企微第二窗口与主窗可近乎同尺寸；如果 ScreenCaptureKit 无法唯一匹配 AX 窗口，必须拒绝截图，不能猜测。真实云端调用与联系人写入须分别验收，不以 fake 代替。
