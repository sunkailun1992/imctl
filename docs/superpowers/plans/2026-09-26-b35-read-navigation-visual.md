# B35：读取前可逆导航视觉轮次实施计划

> 目标契约见 `docs/superpowers/specs/2026-09-26-b35-read-navigation-visual.md`。本页列实施与验证顺序，真实企微 / 千问 / MQTT 是否通过由后续 B35 门报告记录；不能从 fake 成功推断活体通过。

## Task 1：锁定入口和无动作分支

1. 在 `message.history` 普通读取定位最新之前，只对显式命令、单个可见且可写的消息区竖向 AX 滚动条考虑主动轮次。先读 AX 值；已在底部则保持零截图、零模型请求并正常返回最新可见页。`scrollback:true` 的旧历史加载不进入这条新的单滚动条主动路径。
2. 在联系人申请页导航中，先读唯一精确「新的客户」AX 行的选中状态和右侧申请表就绪状态。已选中且表已就绪时保持零模型请求；否则在显式 `contact.request.list` 的可逆选行前缀进入主动轮次。`contact.request.accept` 可使用同一只读导航函数，但卡片匹配与接受按钮留在原命令实现。
3. 视觉未启用、不是外部显式命令或后台调用时，保留现有 AX 路径与权限、策略边界。不要为了增加模型计数而滚动一个已在底部的会话或重新选择已就绪的新的客户行。

## Task 2：实现受限的动作前后两轮

1. `message.history` 的模型候选只含本轮消息区唯一可见、可写的竖向滚动条；目标值由命令固定为最新端，不由模型提供。选中后再次核对活跃会话、策略、PID、主窗口、候选句柄、frame、role 和可写性，再写 `AXValue`。重取窗口截图作动作后模型观察；第二轮仅可 `verify` / `reobserve` / `stop`，最后重读滚动条 AX 值达到底部才返回最新消息。
2. `contact.request.list` 的模型候选只含左侧 outline 中唯一可见、精确标题「新的客户」且可通过 `AXSelectedRows` 选中的行；右侧同名标题不能入候选。选行前重核窗口、row / outline 句柄、frame、role、方法、授权与策略；动作后新鲜截图模型复核，再以 AX 选中行及右侧新的客户表就绪的组合证据返回。`contact.request.accept` 的共享导航也必须在任何接受动作前通过这些检查。
3. 两步共用已有有界可逆轮次与匿名诊断计数。模型仅能选择当前候选 ID 或停止、重观察，不能生成坐标、滚动值、申请对象或成功结果；动作后模型 `verify` 必须再经过方法所属 AX 后验。失效候选、模型 `stop`、截图失败、提供商报错、预算到期及中途准入变化全部失败关闭。

## Task 3：聚焦 fake 和安全回归

1. 写 fake AX + 假模型测试：单一可写滚动条虽无歧义、仍在确需到最新时产生两轮；到最新后值读回并返回新页。已到底部零上传；单候选不可见 / 不可写、多个候选、值未落地、动作后模型 `stop` 或错误均不把旧页当新页。历史 watcher 不滚动也不上传。
2. 写联系人申请测试：唯一可见精确行进入两轮；已选中且表就绪零上传；右侧同名标题、重复左侧行、无可操作 AXRow、选中未落地或表未就绪均停止。接受命令只复用导航前缀，模型拒绝时不能选卡片、点接受或落 checkpoint。
3. 回归 B34 的选会话两轮、其它命令 AX 路径、暂停 / 策略 / 身份 / PID / 窗口 / frame / 候选变更阻断以及 `controller.describe` 计数语义。运行聚焦测试、`swift build`、全量 `swift test`、`git diff --check` 与敏感扫描；不把截图、模型原文、密钥、真实联系人或 broker 写入报告。

## Task 4：受控活体与门报告

1. 主执行者使用稳定签名的本机应用读回 `setup --check` 六项、视觉设置和 `controller.describe` 三项数值基线；先确认客户端处于确需导航的状态，再各发一条显式 MQTT `message.history` 与 `contact.request.list`。只读 / 可逆验收不发送、不接受申请、不修改联系人。
2. 分别记录计数前后差分、是否确实触发两张新鲜窗口帧与两次模型请求、模型决策对应的允许动作、AX 滚动条底部值或新的客户选中与表就绪、命令终态及 `command.get` / 后续只读核对。计数是进程级总量，HTTP 200 不是成功后验；以方法 AX 证据和 MQTT 终态共同判定。若样本已到底部或新的客户已选中，应报告零上传与“该活体未覆盖主动分支”。
3. 门报告分开记录源码 / fake、真实 Qwen、企微 AX、MQTT、本机安装、最终 release 与第二台 Mac；四个写命令、接受按钮和其它桌面方法仍按其各自门报告结论，不能由 B35 两个读取前缀推及全命令覆盖。
