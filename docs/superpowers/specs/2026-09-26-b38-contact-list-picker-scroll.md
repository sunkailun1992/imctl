# B38：contact.list 选人面板联系人滚动视觉轮次

显式 `contact.list` 已经通过 `ActionPolicy` 打开本命令拥有的唯一「发起群聊」面板。先读当前可见联系人；若已达到 `limit`，直接取消，不截图。若仍需遍历，仅对大纲直接父区中唯一可见、可写、与大纲同高且靠右的垂直 `AXScrollBar` 开启视觉步骤；多个候选、几何不符或面板身份变化均失败，不猜第一条轨道。

模型在首个确需改变的固定位置前，只能从这条当前 AX 候选中返回 `scroll`、`reobserve`、`verify` 或 `stop`。命令负责 `0 / 0.25 / 0.5 / 0.75 / 1` 的目标值，模型不能更改。AX 写入后刷新企微窗口并做第二次模型观察，再由同一 PID、窗口、面板、大纲、滚动条和 `AXValue` 读回证明首个位置。余下位置复用同一滚动条，逐次复核权限、策略、暂停、命令时间预算和 AX 身份，不再上传；只读完成后按原路径取消本命令面板。

单条读取命令最多 4 轮、2 次首位置 AX 尝试、60 秒；屏幕录制、云端、整窗本机许可缺失时沿可验证的 AX 路径。后台自动轮次不启用视觉。模型只能否决或定位这一可逆滚动，不能改联系人、发消息、选择成员或确认建群。真实企微与 MQTT 活体验收单列，不把 fake 测试记为完成。
