# 群改名提前生效的结果核对

用户报告：客户端已改名，但第二轮群名视觉观察在首次请求前因旧群名不再匹配而返回 `staleView`，命令为 `unknown`。本次修复沿用原 `group.rename` 参数、策略与幂等语义。

- 群名 `AXValue` 写入可能已经提交，不能继续保证它可逆。显式改名在首次写值前记录一次 checkpoint，之后不为 `AXConfirm` 重复记录；`group.create` 保持原时机。写值前后仍执行原策略、字段与窗口核对。
- 写值前冻结唯一选中的原群行 handle、窗口 PID / frame 与编辑栏 handle / frame。仅同一原行仍唯一选中、列表中请求名唯一、活动头部与唯一原编辑栏都精确为请求名时，允许认列提前生效；名称不同于旧名。
- 独立只读核对仍受原命令、暂停、政策快照、录屏、视觉开关、模型配置和预算约束。只读核对可接受原群已变新名，普通写入与确认的旧目标门禁保持不变。
- 提前生效证据成立就结束，不再发送确认或失焦。第二轮仅在本次 `staleView`、且模型没有停止或返回非法操作时允许同样核对；模型判断不能替代 AX 证据。
- 头部回显、另一同名群、重复新名、原行 / 字段 / 窗口变化、配置或政策撤回均不得凭此报告成功。checkpoint 后缺证据保持 `unknown`；同键重放，不重新提交。
- 完成 hook 在准备与恢复 catch 之外，保留崩溃注入语义。真实改名验收需明确测试群、临时名称、恢复名称与次数；没有执行就记录待活体。
