# B30 群成员选择身份复核规格

## 范围

`group.create` 与 `group.addMembers` 在选人面板的搜索、回车选择阶段共用 `pickMembers`。现有路径在回车后仅验证右侧已选表行数增加，不能证明新增行是请求的人。本批只收紧这一可取消的面板阶段，不增加协议字段、模型权限、按键或真实加人动作。

## 安全口径

- 搜索后的唯一首行仍由 AX 姓名决定；回车前再次读取当前面板、搜索值、过滤状态、唯一结果与已选名单。重读不符即停止。
- 回车最多一次。回车后右侧已选表每一行须提供唯一 AX 文本，新名单应恰为旧名单追加请求姓名。人数增加但身份不明或不符即失败，调用方取消面板，不进入 `完成` / `确定` 或 checkpoint。
- 模型不能替换成员身份、选另一人或触发最终确认。既有确定按钮歧义选择机制不因此扩权。
- 真实客户端已选行的 AX 文本形态需要活体只读校准；如无可靠文本，保持失败关闭。

## 验收

Fake 覆盖正常两人选择、选错人、无可读姓名、回车前搜索结果变化；错误路径没有第二次回车、确认或 checkpoint。全量测试、编译、敏感扫描通过，真实群操作保持 0 次。
