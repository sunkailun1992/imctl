- **程序坞 + 菜单栏**：控制台从「只在菜单栏」改为常规应用（`NSApp.setActivationPolicy(.regular)`，程序坞显示新图标），菜单栏项保留；点程序坞图标或菜单栏「打开控制台」都能把窗口叫回来（关闭窗口只是隐藏，`WindowHider` 拦截 `windowShouldClose`）；程序坞右键菜单「打开控制台」；菜单栏与状态页各有「在程序坞显示图标」开关（`DockPresence`，UserDefaults `showInDock`，默认开）。
