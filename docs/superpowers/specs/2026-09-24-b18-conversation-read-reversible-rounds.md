# B18：`conversation.read` 解析遗漏时的有界可逆视觉轮次

## 背景与范围

B17 为显式固定桌面命令建立 AX 优先、云端视觉候选后备，但跨轮选择仍主要由各动作自行重试。B18 先在 `conversation.read` 的一个可验证场景接入可复用循环：目标会话标题没有进入几何解析结果，却仍出现在侧栏某一行顶部的 AX 文本中。客户端重建侧栏时，一次 `AXSelectedRows` 可能未生效；本批允许重新读取、重新选择，再以活动会话标题核验。

本批只改变 `conversation.read` 的**可逆选行步骤**。MQTT / MCP 方法、参数、结果、topic、事件及错误码不变；不增加任意自然语言任务、坐标点击、全局输入或新权限。发送、发文件、接受联系人、建群、改群与广播等不可逆步骤仍按 B17 原有流程，不能把本批称作所有桌面命令的通用 AI 执行完成。

## 进入条件与执行路径

1. 命令必须来自显式外部固定协议调用，方法为 `conversation.read`；执行器原有过期、暂停、目标、身份与策略检查先行。后台 watcher 不进入本循环。
2. 当前会话已是目标时，直接按原有读路径返回；解析器找到唯一目标行时，沿原有 AX 快速路径选行并复核，不拍照、不调用模型。
3. 仅当解析器漏掉目标行、侧栏行顶部 AX 文本有目标的精确标题，且 B17 视觉入口已启用时，才进入可逆循环。若同屏有多个精确标题行，按目标歧义失败；模型不能替调用方猜选重名会话。无精确标题行也失败。
4. 循环前及每轮模型调用后，重新检查命令来源和方法、暂停、目标身份桥、策略、企微 PID / 窗口、当前 AX 候选。屏幕录制、`cloudEnabled`、`fullWindowEnabled` 三门缺一，不上传完整窗口。上传只限本机验证过的企微窗口单帧，截图和模型请求 / 响应不落盘、不进入 MQTT 或日志。
5. 模型只可在该轮新鲜 AX 候选中返回 `selectRow`、`reobserve`、`verify` 或 `stop`。只接受当前目标标题唯一行的候选 ID；不用模型给出的自由文本、坐标、目标变更或“成功”判断。执行前重新验证候选句柄、角色、PID、窗口和标题；动作只写侧栏表的 `AXSelectedRows`。
6. 每轮动作后重新读活动会话标题。只有标题等于原目标，且随后读取的活动会话头部仍相符时，`conversation.read` 才按原结果结构返回成功。`verify` 只是请求重读 AX，不使模型自评成为成功证据。窗口、目标、策略或暂停状态变化、模型拒答 / 含糊、AX 证据不足时停止并给出既有失败语义。

## 有界性与安全语义

- 一条命令最多 **2 次侧栏选行**、**6 次视觉推理轮次**、**40 秒**；同时受原有命令级预算与单次模型请求时限约束。达到上限即停止，不递归、不自动换模型、不使用新幂等键重投。
- 每次候选都来自重新读取的 AX 树，旧句柄不能跨轮沿用。模型只能选已列出的 ID，不能提出新 AX 元素或扩大动作集合。
- 视觉请求与读取结果不能放宽 `ActionPolicy`、目标白名单、暂停和身份桥。策略在推理等待期间被撤销时，不得再写 `AXSelectedRows`。
- 本批不经过不可逆 `submit`，不增加 checkpoint 或发送。纯读命令的重复调用可能重新观察或重新上传；调用方应按既有命令记录与事件语义对账。

## 验收口径

| 层次 | 需要证明 |
|---|---|
| fake AX / fake 视觉 | 解析遗漏且标题唯一时，首选行未落实、第二轮重读并选中可成功；模型 `verify` 无 AX 后验仍不能成功；候选伪造、旧窗口 / 旧句柄、重名、无标题、停止、超轮次 / 超时均无越权 AX 写。 |
| 门禁 | 已在目标会话、普通唯一 AX 行、策略拒绝或视觉三门任一关闭时无整窗请求；推理期间暂停 / 策略 / 目标身份变化会阻止选行。 |
| 活体 | 稳定签名应用上的显式只读 MQTT `conversation.read` 返回的活动标题与企微 AX 读回相同；分别记录是否真正触发解析遗漏和云端请求、延迟与终态。普通路径成功不能替代真实视觉分支验收。 |
| 发布 | `swift build`、`swift test`、守卫测试、secret 扫描、签名安装与本机授权读回分层记录；门报告逐项写明 fake、活体、安装和第二台 Mac 的证据边界。 |
