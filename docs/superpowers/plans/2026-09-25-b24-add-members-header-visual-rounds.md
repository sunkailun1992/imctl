# B24：添加群成员标题栏可逆视觉轮次实施计划

> 规格见同日 B24 文档；本计划不代表活体验收。

1. 保留 B14 已打开空面板和唯一精确 `AXHelp` / `AXValue` 按钮的 AX 快路径；将右侧标题栏候选限定为可按、启用的 `AXButton`，剔除“完成 / 确定 / 发送”类标签。
2. 为 `AIPlannerReversibleRunner` 增加**方法和目标专属**的标题按钮入口，限制 4 轮、2 次按压、24 秒；普通 runner 对 `press` 继续拒绝。由 `WeComCommandHandler` 仅向显式 `group.addMembers` 安装回调，动作层不接收模型任意动作。
3. 每轮重新定位企微主窗、活动群、人数和候选；截图、推理及最终 AXPress 前重验命令来源、视觉许可、暂停、策略、原授权、目标身份及 PID / 窗口 / 候选。按压后等 B14 面板标题和空已选表；错误面板取消并读回关闭；全部失败按既有 `ACTION_UNAVAILABLE` 路径停下。
4. 用合成群窗口和假视觉模型验证两轮成功、错误面板清理、AXHelp 零请求、中途撤销及候选漂移，并断言无 checkpoint / `确定`。运行聚焦测试、`swift build`、全量 `swift test`、diff 和 secret 扫描。
5. 主任务负责签名安装后的显式只读 MQTT 与真实客户端取证；不执行加人或发消息。真实含糊标题按钮若未出现，模型轮次待活体，不能用 fake 冒充。
