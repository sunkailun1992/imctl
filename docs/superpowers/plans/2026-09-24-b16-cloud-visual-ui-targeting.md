# B16 实施计划：云端视觉辅助 AX 控件定位

## 全局约束

- 用户已授权外部视觉 API：默认千问、可在本机切换 Gemini / DeepSeek，只上传裁剪的相关控件区域。B15 媒体方向仍本机判定；常规 MQTT / socket 读取及观察零云端请求。
- 不新增合成鼠标 / 按键；所有改变客户端状态的动作先经过 `ActionPolicy`，不可逆点、幂等与复核规则不变。密钥只在本机受限存储，任何提交、日志、测试输出或门报告不包含真值或真实聊天。
- 在首个 B16 活体前只用合成截图与假传输；首个真实客户端试点限定用户测试群的「添加群成员」标题栏控件，先走 dry-run / 不确认成员变更。不要用生产联系人验证。

## 任务 1：配置、密钥与提供商

1. 先写配置测试：默认千问、三家独立密钥、禁用 / 缺密钥失败关闭、本机替换 / 删除后不回显、文件 0600 / 父目录 0700（或等价系统凭据存储）、坏文件拒绝。已有本机千问密钥的一次性导入只读取源进程 / 文件中的密钥到内存，不在参数、stdout 或测试记录中显示；地域未知时先停。
2. 实现本机配置与 CLI / 控制台入口。提供商 / 模型切换只经本机；MQTT、`policy.set`、模型输出都不能更改。状态只显示提供商、模型、启用与密钥是否存在，屏幕录制状态单独显示。
3. 将受支持模型名单与每家官方端点规则做成显式配置；千问按地域及必要的工作空间 ID 选择官方域名，Gemini 与 DeepSeek 用各自官方地址。配置不接受任意完整 URL。

## 任务 2：受限网络传输

1. 先用 URLProtocol / 假传输覆盖三家请求头、固定 HTTPS/443 主机 / 路径、内联 Base64 一张图、短超时、大小上限、无缓存 / Cookie、重定向拒绝；无图片 URL / Files API。测试恶意提供商字符串、任意 URL、IP 字面量、401 / 429 / 5xx / 超时、畸形响应和敏感日志。
2. 实现窄接口：入参是裁图字节、静态任务及候选 ID 集；出参只有一个被校验的候选 ID 或明确失败。提示词与返回值没有工具调用能力，网络错误只给脱敏分类与耗时；一次显式操作最多一次请求，不自动转第二家。

## 任务 3：控件带裁图与 AX 候选

1. 对合成窗口图先写单测：AX 全局点与截图像素按显示原点 / Retina 缩放换算，严格裁到预定义控件带，遮掉标题、聊天正文、头像和窗口外像素；检查最大边长 / 字节数、窗口跨屏 / 离屏 / 移动 / 遮挡时拒绝。内存中编码，不写临时文件。
2. 复用已核对企微 PID / AX 几何的单帧截图原语。收集当前操作的候选 AX 元素、稳定的短 ID 与框；初始只覆盖 `group.addMembers` 标题栏歧义按钮。没有候选 AX 动作时停止，不用鼠标坐标点击。

## 任务 4：动作接线与复核

1. Fake AX 测试先证明：策略拒绝、AX 唯一目标、常规历史 / 观察均不触发截图或云端；模型选非候选、双候选或带命令文字、界面 / 会话 / PID / 句柄变化均零 AX 写；模型有效时仅对唯一候选执行预期 AX 动作并读回验证。
2. 在原 `CommandExecutor` 与 `WeComActions` 流程中加窄 fallback，授权在截图 / 上传之前；模型结果不可修改目标、策略、发送内容和状态机。已发生不可逆步骤后的不确定结果沿用 `unknown`，不重跑。

## 任务 5：文档、验收与交付

1. 更新 `ForbiddenAPITests`、协议文档（仅当新增对外方法 / 状态 / 错误码）、控制台「授权与本机」与设置、随包说明。明确系统屏幕录制权限与云端视觉开关分离；现有 B15 路径不外传。
2. 运行 `swift build`、`swift test`、`bash scripts/check-secrets.sh`、`git diff --check`，检查配置和二进制包中无密钥。先用假传输，再做目标 Mac 上的显式、脱敏活体；记录云端请求数、耗时、AX 复核、发送数与失败路径。
3. 把实测写入 `docs/gates/2026-09-24-b16-cloud-visual-ui-targeting.md`；未完成项保持待验。提交 / 推送仓库后按 wiki 12 步归档用户决定、当前口径与待复核项；第二台 Mac 单独检查授权、配置和地域端点。

## 回退

本机关闭云端视觉开关即可停止外传；撤销某家密钥只影响该提供商。代码回退恢复原 AX 路径和 B15 本机方向识别，不需要迁移消息、策略或 MQTT 事件；已发给外部提供商的裁图不能靠本机回退撤销，门报告须如实记录调用次数。
