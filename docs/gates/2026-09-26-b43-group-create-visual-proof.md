# B43 建群选人身份与新群后验 — 代码和 fake 通过，活体待验

## 范围

- 显式 `group.create` 保持固定 MQTT 参数、既有策略、幂等键、checkpoint、逐人搜索与一次回车选人。模型只能在命令自有「发起群聊」面板的「完成」前，以及 AX 已证明新群后，分别做受限的 `verify/reobserve/stop` 整窗观察；每次重读同一企微窗口、PID、位置、策略和本机视觉设置。后台观察与未启用视觉的路径不上传。
- 「完成」前、checkpoint 后和 AXPress 前，已选表可读姓名必须依请求顺序精确一致；同数量不同姓名、缺姓名、重复请求均不进入不可逆点。前置失败尝试关闭本命令面板。
- 「完成」后等待至多 10 秒，但成功只认 **新插入且唯一选中的会话行**：旧可见行身份保留、行数恰加一、新行先前不存在、群头标题与新行一致，并有请求成员加本人的精确人数，或无人数时自动群名含所有成员的独立姓名段。旧群人数、任意标题变化、列表重建或虚拟化导致身份不明均为证据不足；checkpoint 已过则 `unknown`，不补按「完成」也不同键重建群。只有这一后验成立后才可执行可选的命名步骤。

## 验证

| 层 | 结果 |

| 本机企微 / MQTT | 本隔离批次未执行；新建群 0 个、发送 0 条、真实模型请求 0 次。真实创建需要可核对的两个自有测试成员和独立授权。 |

## 未闭环

- 真实客户端可能重建侧栏 AX 行，导致无法保留原可见行身份。本实现会保守地返回 `unknown`；需在自有测试群验收后按真实 AX 证据调整，但不能退回“标题变化即成功”。
- `group.created` 仅在执行器收到 `opened:true`、请求命名满足且已越过 checkpoint 时产生；本批未验活体事件。
