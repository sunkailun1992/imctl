# 会话最新定位与媒体类型实施计划（2026-09-23）

## 全局约束

只读解析和观察事件字段；不改发送、策略、白名单、键鼠、凭据或运行数据。真实联系人标题、正文和签名地址不进入代码、测试、文档与提交。客户端仅从 AX 证据推断类型；保留 `unknown`。控制台不恢复行内图片或视频播放。

## 实施顺序

1. 在 `MessageRow` 增加媒体子类型，并用当前选中行预览对最后一条无文本媒体做保守分类；先写 fake AX 正反例测试。
2. 同步 `message.history` 与 `WatchSnapshot` / `WatchEngine`，补 MQTT 事件泵透传测试，更新 `docs/protocol/im-control-protocol.md`。
3. `conversation.read` 复用一次解析出的消息，保持计数、类型、策略与目标复核；加解析次数回归测试。
4. 控制台按类型显示文件、视频、图片和未知媒体；普通历史完成时滚到最后一条，回滚不强制滚到底；加模型与标签测试。
5. 跑 `swift build`、全量 `swift test`、`git diff --check`、secret 扫描；做可脱敏的本机只读核查，写门报告并提交推送。再更新安装包、随包文档与 Wiki 交接。
