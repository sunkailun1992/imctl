# B39：添加群成员标题按钮进入双轮视觉路径

## 范围

显式 `group.addMembers` 在整窗视觉许可已启用时，打开群成员面板的固定标题按钮进入 `AIPlannerReversibleRunner`。即使 AX 的 `AXHelp` / `AXValue` 已精确标为「添加群成员」，仍先截图让模型在该唯一安全候选中选择；面板打开后，再对同一企微窗口截图一次，仅允许模型 `verify`、`reobserve` 或 `stop`，并以新鲜 AX 读回同一面板句柄、标题和空已选表决定能否继续。

初始已有任何 sheet 时不截屏、不取消、不复用；此规则也用于视觉关闭时的确定性路径。无安全标题候选、多个同名精确候选、窗口 / 会话 / 人数 / 策略变化或模型无法确认时终止本次操作。按钮按下后若出现其它类型或已选成员的面板，不再取消，也不尝试第二个按钮，因为无法确认面板归属。若第二轮未获确认，只对本命令打开、句柄未变且仍为空的「添加群成员」面板执行确定性「取消」清理；被替换、有人选中或会话变动时不碰该面板。没有名称的标题按钮仍限右侧、可见、可按压且排除危险语义，模型只能从当轮至多两个 AX 候选中选择一个。第二轮的「取消」按钮只作为已打开面板的视觉标记，不能由模型按下。

成员搜索、已在群内与找不到成员的处理、`dryRun` 取消、最终「确定」、checkpoint、幂等和终态证据沿原实现。安全补丁在选人后、checkpoint 前、hook 后与 AXPress 前重新核对实时策略、暂停状态、窗口 PID / frame、活动群及精确已选成员名字和行句柄；checkpoint 后拒绝由命令执行器归为 `unknown`，不报告 `failed`，也不按「确定」。本批不扩大可选成员，也不让模型决定成员身份或确认。视觉开关关闭或诊断探针仍走原 AX 路径。

这只覆盖 `group.addMembers` 的**打开面板前缀**。选人和最终确认仍为确定性 AX 流程；真实新增成员的多轮视觉与端到端写入证据待单独验收。
