# B48：用实时 AX 结构定位可识别控件

## 目标与边界

- 用户决定：跨 Mac 和屏幕尺寸的定位应优先使用当前企微的辅助功能元素；不以录制时的屏幕坐标决定点击位置。
- 本批调整可由 AX 结构独立证明的布局解析：通讯录「新的客户」行和卡片表、会话搜索栏旁的「+」按钮。若精确「新的客户」行已选中，命令跳过重复选择与视觉上传，继续核对卡片表。保留窗口内可见性和所属容器的实时几何校验，歧义时不选控件。
- 模型仍只在显式固定命令中选择本轮 AX 候选；不接收自由坐标，也不新增截图、上传、按键或协议字段。
- 不修改策略、白名单、checkpoint、MQTT、守护进程、运行数据或安装包。本批客户端发送数为 0。

## 实施与验证

1. 用已录制并脱敏的 AX 夹具及合成布局变体证明：左栏宽度、窗口原点、顶部高度变化时仍选择正确的行、表和「+」按钮；同名或同位置候选歧义时停止。
2. 改解析层，使候选来自 AX 角色、父子关系、可设属性和当前控件的实际 frame；删除上述路径中用于筛选的固定窗口距离。
3. 运行 `swift build`、`swift test`、`bash scripts/check-secrets.sh`、`git diff --check`。在已授权的本机只做脱敏只读探针；新构建未安装前，不把旧安装版的表现算作本批活体验收。
4. 将结果与未闭环项写入 `docs/gates/`，同步 `docs/ops/portability.md`。

## 留待独立证据的路径

- 后台通讯录角标在现有 AX 树中没有可验证的「通讯录」语义标签，不能把固定纵向范围直接替换为另一个顺序或坐标猜测；后台观察也不能调用云模型。需要角标大于零且侧栏变化的脱敏 AX 样本，才能安全改归属判定。
- 群成员、联系人添加和群名编辑涉及可写命令，须分别提供失败关闭测试与目标机活体后验；本批不把只读布局测试推断成这些写路径或第二台 Mac 的通过。
