# 控制台界面整理（2026-09-23）

## 目标与范围

用户提供现有状态页截图：全屏时内容集中在窄列，大片空间闲置；窗口标题与页面标题重复；进程、授权、策略和维护按钮同级堆放，难以先判断运行情况。此次只改 `imctl-console` 的 SwiftUI 页面布局和文案，不改守护进程、策略文件、命令语义或客户端控制路径。

## 实现

- 状态页先显示守护进程、企业微信、辅助功能、发送范围四张概览卡；`allowAll` 开启时显示显眼提示。常用操作独立成区，运行详情、授权、本机设置和守护进程维护折叠显示。卸载按钮增加确认。
- 侧栏按概览、日常操作、监控、配置、参考排序；窗口标题改为应用名，页面标题只保留在正文；调整默认及最小窗口尺寸。
- 发送、通讯录、策略、设置按任务分段；会话页收起改群名操作，媒体签名地址不再直接占据一整行；事件筛选与文档切换控件收紧。
- 既有发送、建群、策略写入仍调用原 `ConsoleModel` 方法；未添加自动动作。暂停按钮仅在暂停原因包含 `api` 时提供恢复。
