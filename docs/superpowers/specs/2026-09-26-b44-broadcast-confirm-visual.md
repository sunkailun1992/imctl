# B44：群发任务确认的受限视觉复核

仅显式 `broadcast.confirm{msgid}` 且本机整窗视觉已启用时增加视觉观察。AX 必须先跨所有企微窗口证明唯一任务：同面板有「群发」、完整精确 `msgid`，以及唯一可用、可按的发送按钮。窗口列表无法枚举、重复任务、泛化面板、多个按钮均在 checkpoint 前停止。模型无权猜任务或改变 `msgid`。

在原 checkpoint 和不可逆 `AXPress` 前，模型只可返回 `verify/reobserve/stop`。每帧验证同一企微 PID、主窗和任务窗句柄及位置、面板和按钮句柄、原 AX 全局唯一性、当前暂停/策略、录屏和视觉设置。每次 `reobserve` 使用新帧，合用显式命令的六轮/40 秒上限。模型通过仍只准原代码按一次。

按后按钮消失或禁用时保持原 AX 成功证据，不制造第二帧；若同一面板及可用按钮仍在，可复核新帧，但只有 AX 后验能决定成功。checkpoint 后证据不充分为 `unknown`，同幂等键不二次提交。真实群发助手 AX 形态、云端帧和 MQTT 终态仍待专项活体样本及授权。
